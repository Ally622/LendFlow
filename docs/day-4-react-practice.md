# Day 4 — React Practice

## Goal

Strengthen my understanding of React fundamentals before continuing to build the LendFlow application.

## What I Learned

### 1. React Components

Components are reusable parts of a user interface. I created a `Welcome` component and reused it more than once.

### 2. Props

Props allow a component to receive information from another component. I created a `Customer` component that displays different customer names.

### 3. Arrays and Lists

I used an array to store customer names and `.map()` to display each customer. I also learned that React uses keys to track list items.

### 4. State with useState

I learned that `useState` lets a component remember information and update the interface when that information changes.

### 5. Click Events

I used `onClick` to respond to button clicks and update a counter.

### 6. Page Refresh

I observed that React state resets when the page refreshes because the initial state is set again.

## Practical Exercise

I built a LendFlow Customer Manager that displays a customer count and an Add Customer button. Each click increases the count by one.

## Key Concepts

* Components make interfaces reusable.
* Props pass data into components.
* Arrays and `.map()` help display lists.
* `useState` manages changing information.
* `onClick` handles user interactions.

## Project Structure

I used a separate React practice project for these exercises. The main LendFlow frontend remains a React + TypeScript + Vite project.

## Day 4 Outcome

I practised React components, props, lists, state, and events. I am now better prepared to continue learning React and TypeScript before implementing the LendFlow interface.

## Next Steps

Continue learning React and TypeScript, then apply these concepts to the real LendFlow frontend.
