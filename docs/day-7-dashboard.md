# Day 7 — LendFlow Dashboard UI

## Objective
Improve the customer manager interface and build a responsive loan management dashboard.

## Features Implemented
- Created a dashboard layout with a sidebar and header.
- Added summary cards for customers, total loan amounts, approved loans and pending loans.
- Styled the customer registration form.
- Kept name, phone number and loan amount validation.
- Added customer search by name or phone number.
- Displayed customer records in a table with approval status badges.
- Added responsive CSS for smaller screens.
- Calculated dashboard totals from the current customer state.

## Technologies
- React
- TypeScript
- CSS
- Vite

## Concepts Practised
- React state and event handling.
- Array methods: `reduce`, `filter` and `map`.
- Conditional rendering.
- Controlled form inputs.
- CSS Grid, Flexbox and media queries.
- Reusable styling classes and responsive design.

## Current Limitations
- Data is stored in memory and resets on refresh.
- Sidebar navigation is not yet functional.
- Loan approval cannot yet be changed through the interface.
- No backend, database, authentication or user permissions are connected.

## Next Steps
- Improve customer management actions.
- Start building the backend API.
- Connect persistent storage in a later stage.
