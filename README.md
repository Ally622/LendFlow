# LendFlow

## 50 Days Full Stack Development Challenge

LendFlow is a Loan, Customer and Business Management System being developed as part of a 50-day full-stack development challenge.

The goal is to build a practical system that can help small financial institutions, SACCOs, MFIs and lending businesses manage their customers and loan operations.

## Project Goals

LendFlow will eventually help an organization manage:

- Customers
- Leads and sales
- Loan products
- Loan applications
- Loan approval
- Loan disbursement
- Repayments
- Collections
- Arrears
- Reports
- Staff users and roles
- Audit records

## Planned Technology

The project will use:

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma
- Git and GitHub
- Docker
- Automated testing

## 50-Day Challenge

During the 50 days I will:

1. Learn a full-stack development concept.
2. Apply what I learned to LendFlow.
3. Test what I build.
4. Commit my work to GitHub.
5. Document important decisions.

## Final Goal

By the end of the 50-day challenge, LendFlow should have a working web application that demonstrates a complete loan management workflow:

Customer → Loan Application → Review → Approval → Disbursement → Repayment → Completion

The project is being built primarily as a learning project to develop practical full-stack development skills.
